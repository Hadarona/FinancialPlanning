# Icon Map

Use the **Lucide** icon family for consistency. Default stroke width: `1.75–2 px`.

| UI purpose | Lucide icon | Default size |
|---|---|---:|
| Email | `Mail` | `20 px` |
| Password | `LockKeyhole` | `20 px` |
| Show password | `Eye` | `20 px` |
| Hide password | `EyeOff` | `20 px` |
| Back | `ArrowLeft` | `24 px` |
| More menu | `EllipsisVertical` | `24 px` |
| Add expense | `Plus` | `24 px` |
| Housing | `House` | `24 px` |
| Groceries | `ShoppingCart` | `24 px` |
| Transport | `CarFront` | `24 px` |
| Fun | `PartyPopper` | `24 px` |
| Savings | `PiggyBank` | `24 px` |

## Rules

- Use outline icons only.
- Keep icon color aligned with the component semantic color.
- Icon-circle backgrounds use the corresponding light tint.
- Do not mix icon families.
- Maintain a minimum `44 × 44 px` interactive target for icon buttons.
